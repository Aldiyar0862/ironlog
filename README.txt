IRONLOG v4.2 — ввод времени бега в разделе «Новая тренировка»

Что изменено:
- При выборе типа тренировки «Бег» автоматически выбирается упражнение «Бег».
- Для результата бега можно ввести дистанцию (км) и время отдельно: часы, минуты, секунды.
- Время отображается в очереди тренировки и в истории как ч:м:с.
- Данные хранятся в той же базе браузера (ironlog_v1); старые записи не удаляются.

Установка:
1. Сделай экспорт JSON из текущего IRONLOG на всякий случай.
2. Распакуй архив.
3. В корне репозитория GitHub замени index.html и sw.js файлами из архива и нажми Commit changes.
4. Дождись зелёной галочки в Actions, затем обнови сайт.

Не загружай ZIP как один файл и не удаляй данные сайта.
