IRONLOG v4.1 — личный тренировочный журнал

Файлы для корня GitHub Pages: index.html, manifest.json, sw.js, icon-192.png, icon-512.png.

Локальный режим работает без Supabase. Для облака открой раздел «Облако», создай личный проект Supabase, вставь Project URL и publishable/anon key, выполни показанный SQL в SQL Editor, затем создай аккаунт/войди и нажми «Первая синхронизация».

ВАЖНО: никогда не вставляй service_role key в веб-приложение. Используй только publishable/anon key и включённые RLS-политики. В разделе «Спорт и активности» для бега время теперь вводится отдельно: часы, минуты и секунды. Старые записи сохраняются; для них время отображается из прежнего значения в минутах. Перед заменой файлов экспортируй JSON на всякий случай. После обновления GitHub Pages обнови страницу; если старая версия осталась в телефоне, закрой приложение полностью и открой заново.
