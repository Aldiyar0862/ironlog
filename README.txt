IRONLOG — обновление 4.1 (восстановление пароля)

Файлы для корня существующего GitHub Pages репозитория:
- index.html
- manifest.json
- sw.js
- icon-192.png
- icon-512.png

Что нового:
- Кнопка «Забыли пароль?» в разделе «Облако».
- Запрос письма восстановления через Supabase Auth.
- После перехода по ссылке появляется поле для установки нового пароля.
- Обновлён кэш PWA, чтобы Chrome запросил новую версию.

Обновление:
1. Сначала скачай JSON-резервную копию тренировок из IRONLOG (если кнопка доступна).
2. Распакуй ZIP.
3. Загрузи пять файлов в корень ТЕКУЩЕГО репозитория GitHub Pages и подтверди замену старых файлов.
4. В Supabase открой Authentication -> URL Configuration.
5. В Redirect URLs добавь точный адрес приложения GitHub Pages, например https://USERNAME.github.io/ironlog/ (замени USERNAME и путь на свой реальный адрес). Если адрес репозитория отличается, используй фактический URL приложения.
6. Сохрани настройки. Не меняй Project URL и Publishable key в IRONLOG.
7. Открой приложение в обычной вкладке Chrome, обнови страницу. Если не обновилось, закрой вкладку и открой снова.
8. В разделе «Облако» введи почту, нажми «Забыли пароль?», дождись письма и открой ссылку на том же устройстве/в Chrome.
9. На странице IRONLOG появится поле «Новый пароль». Укажи пароль не менее 8 символов и сохрани его.
10. Затем войди с этим паролем и нажми «Первая синхронизация».

Важно:
- Не удаляй старое приложение и не очищай данные сайта: локальные тренировки хранятся на устройстве.
- Не публикуй пароль, Secret key или service_role key. Для приложения используется только Publishable key.
- Если Supabase сообщает email rate limit exceeded, не нажимай кнопку много раз подряд; подожди, пока ограничение снимется.
- Если письмо не приходит, проверь Spam/Спам и настройки почты Supabase.
