Облако и синхронизация

Только твой аккаунт. Устройства обмениваются данными через защищённую базу.

Локальный режим
1. Подключение к Supabase настраивается один раз

Нужен личный проект Supabase. URL и публичный publishable/anon key допустимы в клиентском приложении только с включёнными RLS-политиками. Никогда не вставляй сюда service_role key.

2. Личный аккаунт

Не подключено.

Синхронизация и резервные копии

После входа нажми «Первая синхронизация». Локальные и облачные записи будут объединены по ID. После этого новые изменения отправляются в облако при наличии интернета.

Статус синхронизации появится здесь.
Защита данных
  • RLS-политики разрешают доступ только к строке с твоим auth.uid().
  • Не публикуй пароль и не используй service_role key в приложении.
  • JSON-экспорт остаётся отдельной резервной копией.
  • Без интернета данные остаются локально; после подключения отправка повторится.
SQL для приватной таблицы выполнить один раз в Supabase → SQL Editor

Создаёт одну строку данных на пользователя. Политики разрешают читать и изменять только собственную строку.

create table if not exists public.ironlog_data (
  user_id uuid primary key references auth.users(id) on delete cascade,
  data jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now()
);
alter table public.ironlog_data enable row level security;
revoke all on public.ironlog_data from anon;
grant select, insert, update, delete on public.ironlog_data to authenticated;
drop policy if exists "read own ironlog" on public.ironlog_data;
drop policy if exists "insert own ironlog" on public.ironlog_data;
drop policy if exists "update own ironlog" on public.ironlog_data;
drop policy if exists "delete own ironlog" on public.ironlog_data;
create policy "read own ironlog" on public.ironlog_data for select to authenticated using ((select auth.uid()) = user_id);
create policy "insert own ironlog" on public.ironlog_data for insert to authenticated with check ((select auth.uid()) = user_id);
create policy "update own ironlog" on public.ironlog_data for update to authenticated using ((select auth.uid()) = user_id) with check ((select auth.uid()) = user_id);
create policy "delete own ironlog" on public.ironlog_data for delete to authenticated using ((select auth.uid()) = user_id);
Настройка в двух словах
  1. Создай проект в Supabase и подтверди email.
  2. Скопируй Project URL и publishable/anon key из Project API settings в поля выше.
  3. Открой SQL Editor, выполни SQL из этого блока.
  4. Создай личный аккаунт в IRONLOG, подтверди почту (если потребуется), войди.
  5. Нажми «Первая синхронизация» и проверь результат на втором устройстве.
